Original Weather Report weather icon library. PNG files have transparent backgrounds and are alpha-trimmed/scaled by the Tkinter UI for card and tray rendering. SVG files are editable source counterparts kept in the repository, not bundled in the executable. The visual direction follows Fluent-style dimensional weather icons without embedding external artwork.

The set covers the app's mapped Open-Meteo/WMO weather groups: clear, partly cloudy, cloudy, fog, drizzle, rain, freezing rain, snow, snow grains, rain and snow showers, thunder, thunder with hail, and day/night variants where the API provides day-state context. The cloud and unknown icons also serve as startup/error fallbacks. Every PNG/SVG pair is used by these mappings or fallbacks; the tests check coverage in both directions.
